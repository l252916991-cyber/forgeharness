# 多 agent 协作执行计划

日期：2026-10-26。基线：SDK 0.8.5 / API v1；本轮候选：0.8.6。

## 目标与本轮交付

交付一个可选的、固定拓扑的只读专家协作模式：宿主注册专家，分配独立任务和
证据快照，两名或以上专家分别分析，再由协调者综合。所有调用经过现有 R2，
复用持久化、预算预留、取消、授权重验、未知结果对账和 trace。

这是一次专家对应一次受控模型决策的协作；专家没有工具权限。公共 task 对全部
节点可见，私有材料只放入明确分配的节点。默认 ReAct 和原 one-shot 路径继续保留。
本轮实现固定分工的可靠运行与离线契约验收；真实模型质量收益单独验收。

已有三角色实验不支持默认启用多角色，见
`reports/improvement-20261026/REPORT.md`。不复用其中的通过数字来认证新源码。

## 执行批次与验收

| 批次 | 工作 | 验收条件 |
|---|---|---|
| M0 | 冻结设计边界、记录 ADR、释放闲置本地模型 | 计划/ADR 已落盘；oMLX 进程退出且 8000 无监听 |
| M1 | 专家、任务、证据、结构化报告契约；编译为有限 R2 图 | 重复/未知身份、越界证据、无效预算和可变嵌套输入拒绝；相同专家可承担不同稳定任务 ID |
| M2 | R2 模型输出 schema 校验 | 专家结果在下游执行前校验；无效 JSON、越界引用、工具请求保留实际用量并失败；对账同样校验 |
| M3 | 协作构造入口、任务树检查、终验和 keyless 示例 | 宿主授权/资源版本每次重验；专家只见分配材料；任务树展示稳定 delegation ID、状态、用量与预留；重开复用结果 |
| M4 | 回归与故障测试、架构/安全自审 | 预算竞争、重复专家、失效授权、取消、未知响应、重启和重复恢复有回归；blocker/high 已修复 |
| M5 | 版本与文档、不可变候选、全量工程验证 | 源码和干净副本全量门禁、依赖审计、wheel/sdist/最小安装通过；报告记录精确边界和残余风险 |

每完成一批更新执行报告，最终证据保存到 `reports/multi-agent-20261026/`。
候选冻结后不再修改其源码；修复需新候选目录并重跑验证。

## 后续批次（有独立准入条件）

1. **有界并发（下一优先批次）**：按 2026-10-27 的
   [并行执行计划书](EXECUTION_PLAN_PARALLEL_EXECUTION.md)推进单机两个模型节点并发，
   先保证预算、单 owner/state writer、取消与恢复，再做同拓扑串行/并行性能对照。
   不以多角色质量提升为实现前提；默认启用的推荐仍须有目标配置收益证据。
   0.8.6 基线串行；0.9.1 的实现与独立验收见新计划和执行报告。
2. **自主子运行**：注册可执行工具循环的专家，明确父子 checkpoint、审批、超时、
   取消、未知调用和根预算的协议；不可将现有一次 model 节点宣称为自主子运行。
3. **隔离写入**：每个 worker 独立 workspace 或快照，提交补丁和测试证据，统一集成；
   当前工作区无 Git 元数据，不能假定可直接创建 worktree。
4. **真实收益评测**：新协议封存单 agent、固定流程和协作三组，真实审查/修复任务、
   外部验收和人工质量评分；记录成功率、成本、p95、重复劳动和故障恢复。
   未通过判据则保持按场景选择，不能宣称通用收益。

## 模型资源策略

实现、契约测试、故障注入和工程门禁使用 scripted 模型，不需要本地推理服务。
经用户授权，2026-10-26 对已确认监听 `127.0.0.1:8000` 的 oMLX PID 94073
发送 SIGTERM，随后核实进程与监听均退出。仅真实模型评测确有需要时启动服务，
完成后释放进程；本轮不自动执行旧终评或产生新的模型质量结论。

## 完成口径

M0–M5 的工程交付和后续批次分别报告。完整多 agent 路线没有因为最小版本通过而
自动完成。测试替身只证明运行契约；证据引用存在不等于语义支持或专业正确。
