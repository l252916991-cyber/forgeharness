日期：2026-10-16。最终冻结身份和结果位于 `reports/next-candidate/`；旧 0.5.0 报告不认证新树。

## 审查范围

本轮不改变生产 SDK、业务数据库 schema 或业务工具。新增代码是可选 benchmark worker、共同宿主、判分器和验证驱动。核心仍只使用既有依赖；两个上游拥有独立锁文件/环境，发行包不带 benchmark 或环境。

检查了实际引擎调用、原生审批/持久化、宿主保障归属、真实进程退出窗口、取消与核对、失败报告保留、协议摘要、版本绑定、正负判分控制和 CI 接入。完整质量/依赖/源码/干净副本/安装验证以本候选驱动生成的结果为准。

## 保留边界

- protocol 和 lock 固定可重跑的包产物；PyPI 发布产物没有在本轮另行绑定发布 tag 的 Git commit，不以此前 GitHub main 提交替代实际运行版本。
- 共同宿主是只接受固定租户、固定请求身份的合成实验代码，不能作为生产 IAM 或通用会话 SDK 发布。
- minimal 只验证正常只读、原生审批和新进程继续；没有完成各框架原生历史撤回、并发准入及完整故障矩阵。
- equivalent 的权限、来源、稳定请求和业务对账由共同宿主提供；通过率不能归为某个框架原生可靠性。
- 回执丢失后核对的是业务台账；宿主终态不代表原生框架检查点已经自动修复。
- 取消是在工具边界注入的真实 task cancellation；进程退出窗口真实执行，但不是分布式 worker/lease/outbox 证明。
- 上游调用的是确定性 fixture 模型，无真实模型用量、自然语言质量、服务时延、开发者工时或业务效果结论。
- 缺少真实资料、接口、模型预算、独立评审及用户；按用户回复登记，不打开任何业务封存集。
- FH-015–FH-018 继续开放；可选原有 NLTK 风险继续按旧例外审计，新对照环境不自动沿用该例外。
