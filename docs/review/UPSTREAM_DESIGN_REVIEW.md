# GitHub 源码拆解与首项改进审查

日期：2026-10-16。研究与完整建议见
[源码拆解报告](../../reports/UPSTREAM_DESIGN_STUDY_2026-10-16.md)。

## 本轮范围

静态阅读四个官方公开仓库，先固定提交，再取得 17 个源文件/许可证文件；
每个文件均核对 Git blob SHA，并保存 SHA-256。不执行下载的上游代码，
不增加核心依赖，不把源码阅读当作性能、安全或业务质量对照。

本轮唯一生产行为变化是 `ContextCompiler` 的资料预算修复，设计和归属见
[ADR 019](../adr/019-rendered-material-budget.md)。没有改变审批、权限、
工具执行、副作用恢复或数据库 schema。完整请求预算、SDK 简化和执行后端
仅作为后续建议，未标记为交付。

## 缺陷与处理

| ID | 等级 | 证据与处理 |
| --- | --- | --- |
| UDS-001 来源标签与分隔符未计入资料预算 | medium | 同一估算器下旧结果声明 1、渲染结果 40；已改为对完整候选文本估算，必选溢出抛错、可选溢出继续选择，补编译器与 SDK 边界回归 |
| UDS-002 默认字符估算器被称为 conservative | low | 对多语言与不同 tokenizer 无上界证明；文档改称 heuristic，不改变估算公式，也不声称修复真实模型 token 精度 |

审查确认：选择顺序、来源标签格式、公共返回类型保持一致；完整文本估算
不依赖分片可加性；溢出发生于模型执行前；没有新增自动重试或未知写入重放。
自定义估算器仍须遵守原有确定性、非负整数契约。

## 验证和残余边界

修复前的失败回归保存在
`reports/upstream-design-study-2026-10-16/context-regression-before.log`。
新候选使用独立的 `reports/upstream-design-study-2026-10-16/candidate-source.json`
与 `verification/`；旧 `reports/next-candidate/` 和 0.5.0 报告不覆盖新源码。
是否通过全量门禁，以新目录中的冻结摘要及不可覆盖尝试记录为准。

本次改动不关闭 FH-015–FH-018，不新增依赖审计例外，不打开业务封存集。
默认估算不是真实 token 上界，完整请求仍未预算所有 schema/provider 开销；
逐候选估算的潜在二次成本已在 ADR 记录。新的研究快照也不替代之前实际
运行的锁定依赖版本，不代表三方原生完整故障矩阵或独立接入试验完成。
