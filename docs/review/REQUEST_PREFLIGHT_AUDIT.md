# 请求预算与电商只读接入：改动审查

日期：2026-10-17。范围为 ADR 020/021；本地 POSIX/SQLite、确定性模型和 HTTP mock。

## 审查覆盖

检查公共模型兼容、完整 JSON 快照和传输一致性、工具定义改变、规划/执行阶段、
输出预留和未知窗口、历史完整轮次、恢复及协议纠正、trace、SDK 凭据与当前授权、
商品资源/tenant 隔离、完成验收、源码包与最小安装。没有修改业务或 checkpoint schema。

| ID | 分类 | 处理与回归 |
| --- | --- | --- |
| RPB-001 message-only 预算漏算工具与适配器内容 | enhancement | 完整载荷预检；大 schema、动态新工具、选项、输出预留和边界回归 |
| RPB-002 预检后重建内容可能漂移 | medium, fixed | 不可变 JSON 快照，内置格式核对消息/工具/输出上限；HTTP body/hash 对照与禁止重新组装回归 |
| RPB-003 序列化字符串隐藏 credential key | medium, fixed | SDK 对解码后的 request/payload 应用隐私检查；拒绝异常配置，秘密不进入 trace |
| RPB-004 只读接入工具返回后撤权窗口 | medium, fixed | 可选运行授权入口；新工厂要求 callback；查询后撤权阻断下一模型调用，重建后 inspect 仍验权 |

这些问题是本轮实现审查和增强边界，不声称已经证明某个上游存在同样缺陷。

## 具体边界

预检估算为字符启发式，不是 tokenizer 精度或费用测量；单次窗口与累计 actual usage 分开。
未知模型窗口、输出 cap 和内部开销显式记录。generic model 只覆盖 ModelRequest 公共输入，
chat-completions 覆盖本适配器最终发送的 body；提供商内部包装与旧 RAG/chat 不在范围内。
三次准备可能保守拒绝，不能因此自动扩大限额或丢工具。默认未配置 authorize_run 的应用
继续依赖原宿主和会话权限机制。新样例不提供生产认证、真实店铺、自然语言质量或多轮撤回。

既有 FH-015–FH-018 保持开放；旧 NLTK 可选依赖例外不扩大。业务封存集不打开。
没有发布到包索引、外部店铺或真实消息渠道，没有新增运行依赖或真实付费模型调用。

## 候选与完成口径

先冻结新候选，再运行完整质量、评测、安全、依赖、三方组合、干净副本与安装门禁。
证据独立保存在 `reports/request-preflight-2026-10-17/`。旧冻结与失败记录保持原样。
首次已通过候选及其完整门禁在 archive/ 和首个不可覆盖 attempt 中保留；
补调用编号缺陷后重新冻结并运行全套门禁。旧缺陷的只读合成复现和 trace 也单独保留。
是否通过以 `verification/summary.json` 与不可覆盖的 attempt 记录为准；
测试数量不证明真实电商质量、独立接入体验或原生框架优势。
