## 🔧 如何启动真实 LLM 测试

### 步骤 1: 启动 OMLX

```bash
# 检查 OMLX 是否安装
which omlx

# 启动 OMLX 服务
omlx start

# 验证服务运行
curl http://127.0.0.1:8000/v1/models
```

### 步骤 2: 确认模型可用

```bash
# 检查 Qwythos 模型是否安装
omlx list

# 如果未安装，下载模型
omlx download Qwythos-9B-v2-4bit-mlx
```

### 步骤 3: 运行真实测试

```bash
cd /Users/xiaoy/forgeharness

# 运行 50 个测试样本
python3 benchmarks/run_real_llm_eval.py

# 或运行完整 1000+ 测试（需要更长时间）
python3 benchmarks/large_scale_evaluation_real.py --use-llm
```

### 步骤 4: 查看结果

```bash
# 查看详细报告
cat reports/real-llm-evaluation.json

# 对比标准答案 vs LLM 生成
python3 benchmarks/compare_baseline_vs_llm.py
```
