## 对照保障归属

原生引擎实际执行工具循环和审批恢复：ForgeHarness 使用 Harness/SQLite 台账，Deep Agents 使用 SQLite checkpointer/HITL，Pydantic AI 使用 deferred tools 与 Harness StepPersistence。

共同宿主负责当次授权、版本检查、稳定请求、业务幂等、精确业务参数及结果核对。故障场景通过只证明配置后的组合可工作，不能推导自有核心领先。
来源撤回场景第一轮覆盖宿主缓存结果的再次读取；各框架原生多轮历史的撤回传播仍未测。

P1 原生故障矩阵、独立接入体验、真实模型与业务终评仍缺证据。按计划暂停扩大运行时；下一步先补原生矩阵与独立接入评测，再形成有比较依据的长期架构选择。P2 的新业务改动暂未启动。
