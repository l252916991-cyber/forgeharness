# ForgeHarness 产品化 P0 范围

状态：2026-10-27 已建立；P1–P4 工程实现和 P6 工程候选资格已完成，真实 P2/P5/P6 业务接入与验收待外部输入。这里不是业务资格报告。

## 首版选择

- 应用：电商咨询与人工工单。
- 用户：单个可信宿主内的 customer、supervisor、support 及知识维护角色。
- 部署：单机 POSIX / Python 3.12 / SQLite，内部受控访问，模型默认并发 1。
- 主链路：授权咨询 → 当前商品/FAQ 证据 → 有来源的回答；无证据或用户明确请求时进入人工转接 → 独立审批 → 可查询且去重的工单。
- 执行路径：`SessionService` + `Harness`。首版不以 R2、Collaboration 或并行模型接入会话为前置。
- 完成边界：工程、应用接入和业务质量分别判定。真实商家接口不可用时只能交付参考应用资格。
