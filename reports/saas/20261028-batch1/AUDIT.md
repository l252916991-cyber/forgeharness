# 首批候选审查与残余风险

日期：2026-10-28。性质：实施团队交叉代码审查及故障回归，不是独立机构的渗透测试或合规认证。候选结果以 candidate-r3/verification/summary.json 为准。

## 审查范围

架构、身份正确性、当前权限、HTTP 接线、模型/工具边界、备份恢复、并发浏览器响应、测试、依赖、打包与公开能力声明。

| 方面 | 审查结论/证据 |
| --- | --- |
| 核心边界 | 新业务逻辑位于 commerce 应用，SDK API v1 与原单机治理复用；core 无业务/可选平台依赖测试保留 |
| 身份与角色 | 用户 id 独立，凭据查库；管理操作事务内重验权限；工作空间操作不撤销其他空间凭据 |
| 权限时效 | HTTP、SessionService、authorize_run、工具策略与记录策略重验当前主体/资源；模型发送后撤权阻止后续工具 |
| 独立审批 | owner Cookie 和审批凭据分离；当前审批人、精确调用和授权账本再次核对；自批仍拒绝 |
| HTTP | 局部依赖解析、OpenAPI、CSRF 并发撤权和 cookie 删除具备实际请求回归；敏感响应 no-store |
| 请求与页面 | 同业务意图重复提交复用键；页面 storage 仅保存摘要/请求键；换账户/会话后旧结果/错误/审批令牌不得写 DOM |
| 状态与恢复 | 当前全部入口双向校验 app marker；服务锁覆盖初始化和运行；identity 与待审批运行同路径恢复回归 |
| 依赖 | msgpack 1.2.2 审计失败保留，更新锁至 1.2.4；只沿用原 NLTK 例外，无新增 waiver |
| 发布 | 保留 r1/r2 失败/中断证据；r3 重新冻结；基础 consumer 不引入 Web，单独 Web-extra consumer 验证真实安装 |
| 通用 SaaS | PG legacy knowledge 存储不是 SDK 后端；尚无分布式/计费/SLA/真实业务资格，文档明确区分 |

## 审查导致的修正

首次冻结后复现公开角色 demo 可打开私有状态，停止 r1 并修复所有本地入口；随后复现浏览器迟到响应可跨账户展示，加入 generation/abort 与 14 个执行真实页面脚本的回归。r2 因依赖审计未通过而停止，更新 optional lock 后冻结 r3。问题详情与回归路径在 FINDINGS.json。

## 当前接受的本地范围限制

1. 咨询为确定性 fixture，商品目录显式合成；没有实际模型质量或商家业务证明。
2. 真实账户仍是单机邀请制，没有 MFA/密码找回/IdP、平台组织管理和机器身份完整功能。密码节流没有来源 IP/设备级防护，不开放公网。
3. 工作台仅提供工单创建与授权查询；领取/处理/解决、自有工单列表和真实渠道接入是后续工作。
4. CLI 关闭通用访问日志，避免邀请路径凭据进入它的日志；未来反代/网关必须处理日志脱敏，不能直接用默认日志接公网。
5. 应用标记约束当前分发入口，不是 OS 沙箱。同一可信 OS 用户仍能直接读取数据库或运行不识别标记的历史二进制；部署时保持状态目录权限、版本和目录隔离。
6. 恢复限相同机器、相同绝对路径和相同已绑定版本；无跨版本/跨机迁移资格。
7. JS 竞态门禁模拟 DOM/fetch 并执行页面真实脚本；没有完成真人独立试用或真实浏览器布局/兼容性验收。
8. 临时 PostgreSQL 16.2 探测仅证明本机可运行隔离服务端，使用合成状态且已关闭；该旧版未进入项目依赖/生产选型。SDK PG 实现、目标版本测试和进程接管尚未完成。
9. 1000 元/月是用户确认的试点云+模型预算，不是已经发生的采购或容量/SLO保证。没有启动付费云资源或真实模型收费。

若发布范围扩展到公网、真实业务、PG 集群或收费，以上相应限制必须重新设计并通过总计划门禁；本批本地工程资格不随范围自动扩大。
