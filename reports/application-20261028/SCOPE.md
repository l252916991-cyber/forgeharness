# 应用级 W0 范围（A/B 交付）

日期：2026-10-28。状态：已建立。本文件只定义范围与验收口径，不构成业务合格证明。
详细计划见 [执行计划书](../../docs/archive/APPLICATION_PRODUCT_PLAN_2026-10-28.md)。

## 应用与用户

- 应用：电商咨询与人工服务工作台（ForgeCommerce 参考应用）。
- 用户：邀请制账户；角色 `customer`、`support`、`supervisor`、`editor`、`publisher`、`admin`。
- 部署：单机 POSIX / Python 3.12 / SQLite / 单入口 HTTPS，模型默认并发 1。
- 主链路：登录 → 授权咨询 → 当前商品/FAQ 证据 → 有来源回答 → 证据不足时澄清或转人工
  → 独立审批 → 可查询且幂等的工单 → 客服领取与解决。

## 交付等级

| 等级 | 本文件是否覆盖 | 停止点 |
